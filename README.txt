AI SIGNAL TERMINAL V3
======================
This is a front-end prototype inspired by the visual layout in the supplied screenshots.

Included:
- Mobile-first dark trading/casino-style interface
- Live ticker animation
- Asset and timeframe selectors
- Chart-like visual
- CALL/PUT signal panel
- 90%+ confidence filter UI
- Recent signal history
- Countdown

IMPORTANT:
The signal values in this package are simulated UI data. It is not connected to Quotex, Stake, a broker, or a live market feed, and it does not execute trades. A production version needs a lawful/authorized market-data API and a separately tested signal engine.
